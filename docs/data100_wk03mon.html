Boxplots

  • Five number summary:
    • Minimum
    • First quartile (Q1)
    • Median
    • Third quartile (Q3)
    • Maximum
  • Interquartile range (IQR) \(=\) Q3 \(-\) Q1
  • Outliers: unusual points
    • Boxplot defines unusual as being beyond \(1.5*IQR\) from \(Q1\) or \(Q3\).
  • Whiskers: reach out to the furthest point that is NOT an outlier

Adding More Variables

  • Two main approaches:
    • Utilize other aesthetics of the geom
    • Facet: Create multiple plots across the categories of a categorical variable.

Utilize other aesthetics

The basic geom_boxplot() needs an x and a y aesthetic:

ggplot(data = buf,
       mapping = aes(x = as.factor(game_outcome),
                     y = score_diff)) +
  geom_boxplot()

But you can also add color to get another categorical variable on the graph.

Utilize other aesthetics

The basic geom_boxplot() needs an x and a y aesthetic:

ggplot(data = buf,
       mapping = aes(x = as.factor(game_outcome),
                     y = score_diff, 
                     fill = where)) +
  geom_boxplot()

But you can also add color to get another categorical variable on the graph.

Facet

ggplot(data = buf, 
       mapping = aes(x = where,
                     fill = as.factor(game_outcome))) +
  geom_bar(position = "dodge") +
  theme(legend.position = "bottom") +
  facet_wrap(~game_type)

Facet

ggplot(data = buf, 
       mapping = aes(x = where,
                     fill = as.factor(game_outcome))) +
  geom_bar(position = "dodge") +
  theme(legend.position = "bottom") +

Customizing your ggplot2 Plots

  • There are so many ways you can customize the look of your ggplot2 plots.

  • Let’s look at some common changes:

    • Removing the legend
    • Zooming in
    • Using multiple geoms
    • Color!
    • Themes
